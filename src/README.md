# CodeAlpha_HotelReservationSystem

Hotel Reservation System implemented in Java for the CodeAlpha Internship Program (Task 4).

## System Highlights
- **Room Categorization:** Standard, Deluxe, and Suite rooms with pricing tiers.
- **Search & Availability:** Search inventory filtered by category.
- **Reservation Lifecycle:** Make reservations and cancel via Booking ID.
- **Payment Processing Simulation:** Simulates card charging and receipt generation.
- **File Persistence:** Read/write operations save state to `bookings.txt`.

## How to Build & Run
1. Open your terminal inside the project root folder.
2. Compile all files:
   ```bash
   javac -d bin src/*.java
